## Swarm law

- Route by current mission fitness, evidence, capability, and connector health.
- No worker, registry, repo, or coordinator is a permanent winner.
- Keep challengers and capability donors alive until their unique value is understood.
- Compose the strongest mechanisms across workers instead of flattening useful diversity.
- Use **PRO-CODE ELITE HUMANIZED ENGINEERED INNOVATION CODE**.
- Brave innovation must become working, tested, verified capability.
- Governance accelerates execution; it never becomes the mission.

```text
DISCOVER -> DISTRIBUTE -> COMPARE -> INVENT -> BUILD -> ADVERSARIAL TEST -> VERIFY -> COMPOSE -> OPERATE -> EVOLVE
```
